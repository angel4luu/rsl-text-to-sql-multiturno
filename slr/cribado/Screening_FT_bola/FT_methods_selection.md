# Selection process - full-text assessment

Of 85 reports sought for retrieval, 27 could not be retrieved. 58 full-text reports were assessed independently by two AI reviewers (both Claude Sonnet 5.5 (claude-sonnet-5-5), prompted with different expert personas) using the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code; each reviewer recorded one exclusion reason and the page supporting it. The reviewer agents could only read the record file they were given (no web access). Disagreements were resolved by a third AI reviewer (Claude Opus 5.5 (claude-opus-5-5)). The reviewers agreed on include-versus-exclude decisions for 93.1% of reports (Cohen's kappa = 0.835). 17 reports were excluded (E6 Single-turn and schema linking / join inference / execution feedback / self-correction is not a stated central contribution (n = 15); E9 Secondary report of an already included study (deduplication / full text only) (n = 2)); 0 await classification; 41 reports met the eligibility criteria.
