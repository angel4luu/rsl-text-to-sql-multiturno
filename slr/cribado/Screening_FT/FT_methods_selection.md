# Selection process - full-text assessment

Of 595 reports sought for retrieval, 164 could not be retrieved. 431 full-text reports were assessed independently by two AI reviewers (both Claude Sonnet 5.5 (claude-sonnet-5-5), prompted with different expert personas) using the sr-screener skill (version 1.0.0) of the open-source Academic Research Skills suite (https://github.com/Imbad0202/academic-research-skills), running in Claude Code; each reviewer recorded one exclusion reason and the page supporting it. The reviewer agents could only read the record file they were given (no web access). Disagreements were resolved by a third AI reviewer (Claude Opus 5.5 (claude-opus-5-5)). The reviewers agreed on include-versus-exclude decisions for 97.0% of reports (Cohen's kappa = 0.917). 82 reports were excluded (E1 Published before 2019 (n = 1); E2 Article written in a language other than English or Spanish (n = 1); E3 Thesis, poster, abstract-only or extended abstract, <4 pages of content, editorial, proceedings front matter, complete book (n = 1); E5 Not Text-to-SQL over relational databases (KGQA/SPARQL, Cypher, NoSQL, table QA without SQL, general code generation) (n = 6); E6 Single-turn and schema linking / join inference / execution feedback / self-correction is not a stated central contribution (n = 42); E7 No quantitative empirical evaluation (full text only) (n = 4); E8 Single-turn study not evaluated on any public benchmark (full text only) (n = 23); E9 Secondary report of an already included study (deduplication / full text only) (n = 4)); 0 await classification; 349 reports met the eligibility criteria.
