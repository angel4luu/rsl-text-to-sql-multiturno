## R00093 (HIE-SQL)
* **escenario:** MULTITURNO
* **paradigma_principal:** GRAPH_PARSER (Bimodal pre-trained + schema-linking graph)
* **pi3_tecnica_linking:** History Information Enhanced schema-linking graph utilizing Relative Self-Attention over utterances, SQL, and schema.
* **pi3_inferencia_joins:** Pre-existing schema relations (foreign keys) encoded in the directed schema-linking graph.
* **pi4_mecanismo:** Last predicted SQL query and historical utterances are directly encoded as nodes in the context-dependent schema-linking graph.
* **pi4_senal:** Natural language history utterances and the previously generated logical SQL query.
* **historial_eval:** PREDICHO (During inference, it applies the SQL query generated by HIE-SQL in the last turn).
* **Headline Results:**

## R00924 (DIR / RAT-SQL Baseline)
* **escenario:** MULTITURNO
* **paradigma_principal:** REWRITE_PIPELINE (Dialogue Rewriting + Single-turn parsing)
* **pi3_tecnica_linking:** Inherited from the downstream RAT-SQL parser (Relation-Aware Schema Encoding).
* **pi3_inferencia_joins:** Handled by RAT-SQL operating on the rewritten query.
* **pi4_mecanismo:** Two-stage framework: a rewrite model (e.g., RUN) explicitly replaces co-references and ellipses to generate a self-contained single utterance.
* **pi4_senal:** Syntactic co-reference and ellipsis state markers in historical text.
* **historial_eval:** PREDICHO (and GOLD/Oracle evaluated as an upper bound).
* **Headline Results:**
  * SParC (Dev with Oracle Rewrite) · Question Exact Match (QEM) · 59.27%
  * CoSQL (Dev with Oracle Rewrite) · Question Exact Match (QEM) · 52.98%
  * SParC (Dev with RUN Rewrite) · Question Exact Match (QEM) · 49.79%
