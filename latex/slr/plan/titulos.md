# Opciones de título

Cada opción incluye «revisión sistemática» / «systematic review» (PRISMA ítem 1), tiene como máximo 20 palabras y trae un título corto (≤ 50 caracteres) para el encabezado.

## Opción 1

- ES: Restauración del contexto, estado del diálogo y vinculación de esquemas en Text-to-SQL conversacional: una revisión sistemática
- EN: Context Restoration, Dialogue State and Schema Linking in Conversational Text-to-SQL: A Systematic Review
- Título corto ES: Text-to-SQL conversacional: revisión sistemática
- Running title EN: Conversational Text-to-SQL: A Systematic Review
